# Alpaca Guard｜羊駝護羊模擬器

Alpaca Guard 是結合像素農場介面與 Java 隨機模擬的互動應用。調整羊群數量、選擇澳洲州別，即可比較零、一、兩隻羊駝的保護成本與牲畜損失。

![Alpaca Guard 使用的像素農場場景](../web/assets/farm.png)

## 功能

- **農場設定**：輸入農場名稱，調整羊與小羊數量，總數為 1–100 隻。
- **州別選擇**：使用 VIC、NSW、SA、WA 的既有捕食者參數。
- **方案比較**：每個方案執行 10 次模擬，呈現平均成本、成本範圍與平均損失。
- **動畫播放**：選擇方案，逐輪觀看牲畜損失結果，支援暫停、重播及倍速。
- **捕食者分析**：查看狐狸、澳洲野犬、野豬與楔尾鵰造成的平均損失。
- **結果重現**：指定亂數種子，以相同輸入重現相同結果。
- **報告匯出**：下載包含農場輸入、亂數種子與三種方案結果的文字報告。

網頁支援桌面與手機版面、鍵盤操作及減少動態效果設定。

## 本機啟動

環境需求：JDK 17 以上、Git 與現代瀏覽器。macOS／Linux 可直接使用 shell 指令，無需 npm 或外部 API 金鑰。

```sh
git clone https://github.com/SasaWu0136/Alpaca-Sheep-Guards.git
cd Alpaca-Sheep-Guards
sh scripts/web.sh
```

在瀏覽器開啟 **http://127.0.0.1:8080**。保留 Terminal 執行，按 `Ctrl+C` 停止服務。若連接埠已被使用，可執行 `sh scripts/web.sh 8081`，改用 http://127.0.0.1:8081。

命令列版本：

```sh
sh scripts/run.sh 42
```

依序輸入 `Sample Farm`、`VIC`、`80`、`20`。命令列報告輸出至 `output/alpacaSheepGuardViability.txt`；網頁報告透過瀏覽器下載。

## 結果範例

Sample Farm、VIC、80 隻羊、20 隻小羊、亂數種子 42，每個方案執行 10 次。

| 羊駝數量 | 平均總成本 | 平均羊損失 | 平均小羊損失 |
| --- | ---: | ---: | ---: |
| 0 | $3,220.00 | 11.8 | 5.8 |
| 1 | $2,900.82 | 7.0 | 3.4 |
| 2 | $2,722.28 | 3.3 | 0.8 |

這組樣本中，兩隻羊駝的平均總成本最低，比無保護方案少 $497.72。州別、羊群組成或亂數種子改變時，結果也可能改變。

## 系統架構

| 層級 | 實作 |
| --- | --- |
| 領域模型 | `Animal` 抽象類別及 `Sheep`、`Lamb`、`Alpaca` 子類別，描述動物價值與風險差異。 |
| 模擬核心 | Java `Random`、重複試驗、損失歸因與成本計算。 |
| 網頁服務 | JDK `HttpServer`，處理輸入驗證、JSON 回應與靜態檔案。 |
| 互動介面 | HTML、CSS、原生 JavaScript 與 Canvas 像素動物。 |
| 自動檢查 | 23 項模擬回歸檢查、21 項網頁接口檢查，以及命令列報告匯出檢查。 |

瀏覽器向本機 Java 服務送出農場參數，服務使用原有 `Simulation` 類別計算三種方案，再由網頁呈現圖表與動畫。

## 模型假設

成本包含動物損失、羊駝固定費用與維護費。模型使用原始專案提供的價格、捕食者風險及保護倍率，尚未經真實農場資料驗證；每輪試驗沒有指定時間長度。

動畫呈現每輪實際計算的損失數量。動物位置、移動與事件時間為示意，每輪均從完整羊群開始，不代表連續多天的農場紀錄。詳細規則與限制見 [模型說明](MODEL.md)。
