# Alpaca Sheep Guards｜羊駝護羊成本模擬器

## 專案定位
以 Java 開發的命令列模擬工具，比較 0、1、2 隻羊駝三種保護方案，觀察牲畜損失與保護支出的取捨。這個版本以原有學習專案為基礎，整理成可重現、可測試、可介紹的作品集專案。

## 已實作
- 輸入農場名稱、州別、羊與小羊數量；總數為 1–100。
- 支援 VIC、NSW、SA、WA 的既有捕食者參數。
- 每個方案模擬 10 次，呈現平均／最低／最高成本及平均損失。
- 選出本次模擬平均成本最低的方案，輸出文字報告。
- 支援指定亂數種子，重現同一組示範。
- 提供回歸測試與 GitHub Actions 自動檢查。

## 執行方式
需要 JDK 17 以上。在專案根目錄執行：

```sh
sh scripts/run.sh 42
```

依序輸入 Sample Farm、VIC、80、20。執行測試：

```sh
sh scripts/test.sh
```

## 可以展示的技術
| 技術 | 在專案中的運用 |
| --- | --- |
| 物件導向 | Animal 抽象類別及 Sheep、Lamb、Alpaca 子類別 |
| 多型 | 不同動物提供自己的價值與風險倍率 |
| 隨機模擬 | 三種方案各執行 10 次，計算成本與損失 |
| 檔案處理 | 讀取州別參數，輸出模擬報告 |
| 可重現性 | 固定 seed，方便除錯、測試與展示 |
| 品質檢查 | 邊界條件、成本核對、損失歸因及端到端測試 |

## 面試時如何介紹
「這是一個比較羊駝護羊方案成本的 Java 模擬器。我用不同動物類別描述價值與風險，再模擬沒有羊駝、一隻和兩隻的結果。整理版本加入固定 seed 與自動檢查，讓輸出可以重現，也讓成本計算與死亡數量能被驗證。」

請依照自己實際完成與理解的部分調整表述。原始程式署名保留；本次整理內容與原始版本的差異列於 MODEL.md。

## 模型限制與後續方向
參數來自原始專案，沒有提供實證來源。10 次模擬只是示範；成本最低不代表現實農場一定最適合。後續可增加模擬次數、信賴區間、參數設定與 CSV 匯出，再考慮互動式介面。

目前版本沒有網頁介面、即時資料、AI 或正式農場驗證，履歷應以 Java 模擬與物件導向設計為主。
